HandleMCP

Privatliv

Kort sagt: vi gemmer kun din e-mail, hvis du skriver dig på ventelisten. Vi sletter den senest efter 12 måneder, eller når du beder om det.

Hvem

HandleMCP drives af Niclas Johansen som privatperson. Han er dataansvarlig. Skriv til nwj@mail.grokbot.com.

Hvad vi gemmer

Skriver du dig på ventelisten, gemmer vi din e-mail og de svar, du selv giver i formularen. Intet andet.

Hvorfor

Kun for at give dig besked, når HandleMCP uden det tekniske er klar. Grundlaget er dit samtykke. Vi sælger eller deler aldrig din e-mail.

Hvor længe

Vi sletter den i Tally, når vi har givet dig besked om lanceringen. Senest 12 måneder efter, du skrev dig op. Beder du om det, sletter vi den med det samme.

Hvem hjælper os

  • Tally (Belgien) gemmer ventelisten.
  • Umami Cloud tæller besøg og klik. Uden cookies, og uden at gemme din IP-adresse. Vi kan ikke se, hvem du er.
  • GitHub Pages viser siden. GitHub kan logge din IP-adresse af sikkerhedshensyn.

Umami og GitHub er amerikanske firmaer. Data kan derfor blive behandlet i USA. Det sker under EU's regler for overførsel, fx EU's standardkontrakter.

Programmet selv

HandleMCP kører på din egen computer. Dine logins, din kurv og dine ordrer bliver der. Vi ser dem aldrig.

Dine rettigheder

Du kan altid få at vide, hvad vi har gemt, få det rettet eller slettet, og trække dit samtykke tilbage. Skriv til nwj@mail.grokbot.com. Er du utilfreds, kan du klage til Datatilsynet.
